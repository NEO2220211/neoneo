# レシート振り分け(Google Apps Script)

Google ドライブ(マイドライブ)の「受信箱」フォルダに入れたレシート画像を OCR で読み取り、

- ファイル名を `2026-09-25_セブン-イレブン_311円.jpg` のように付け直し
- `振り分け先/2026年/09月/食料品・日用品/` のような年月・カテゴリ別のフォルダへ移動し
- 処理結果をスプレッドシート「レシート処理ログ」に記録します

日付が読み取れなかったレシートや、OCR に対応していない形式(HEIC など)は `振り分け先/要確認/` に移動します。
Google アカウントの中だけで動くので、外部のサービスに画像を送ることはありません。

## セットアップ

1. **フォルダを2つ作る**
   マイドライブに、たとえば「レシート受信箱」と「レシート整理済み」を作ります。
   それぞれ開いて、URL の `https://drive.google.com/drive/folders/XXXX` の `XXXX`(フォルダID)を控えます。

2. **Apps Script プロジェクトを作る**
   [script.google.com](https://script.google.com/) で「新しいプロジェクト」を作ります。

3. **コードを貼り付ける**
   `src/` の中の `Config.js`、`Parser.js`、`Code.js` を、同じ名前のスクリプトファイル(`.gs`)としてエディタに作って貼り付けます。
   `Config.js` の `SOURCE_FOLDER_ID` と `DEST_ROOT_FOLDER_ID` に、手順1のフォルダIDを入れます。

4. **Drive API を有効にする**
   エディタ左側の「サービス」の「+」から **Drive API**(バージョン v3、ID は `Drive`)を追加します。
   (または「プロジェクトの設定」で「appsscript.json をエディタで表示する」をオンにして、`src/appsscript.json` の内容で上書きします)

5. **試しに読み取る**
   受信箱にレシート画像を何枚か入れて、関数 `previewReceipts` を実行します。
   初回は権限の許可を求められるので許可してください。
   実行ログに、読み取った日付・店名・金額と振り分け先が表示されます(この時点ではファイルは動きません)。

6. **振り分ける**
   関数 `processReceipts` を実行すると、受信箱のレシートが振り分けられます。

7. **自動で動かす(任意)**
   関数 `setupTrigger` を1回実行すると、1時間ごとに `processReceipts` が自動で動きます。
   止めたいときは `removeTriggers` を実行します。
   あとはスマホの Google ドライブアプリで、撮ったレシートを受信箱フォルダにアップロードするだけです。

### clasp を使う場合

```sh
npm install -g @google/clasp
clasp login
cp .clasp.json.example .clasp.json   # scriptId を自分のプロジェクトのものに書き換える
clasp push
```

## 設定の変え方(`src/Config.js`)

| 項目 | 内容 |
| --- | --- |
| `FOLDER_PATH_TEMPLATE` | 振り分け先のフォルダ構成。`{yyyy}` `{mm}` `{category}` が使えます。カテゴリ別にしたいときは `'{category}/{yyyy}-{mm}'` など |
| `FILE_NAME_TEMPLATE` | 新しいファイル名。`{date}` `{store}` `{amount}` `{category}` が使えます |
| `CATEGORIES` | カテゴリとキーワードの一覧。店名 → 本文全体の順に、上のカテゴリから探します |
| `DEFAULT_CATEGORY` | どのキーワードにも当てはまらないときのカテゴリ(初期値「その他」) |
| `LOG_SPREADSHEET_ID` | 既存のスプレッドシートにログを書きたいときに指定。空欄なら自動で作ります |

## 読み取りについての注意

- OCR は Google ドライブ標準の機能を使っています。対応形式は JPEG / PNG / GIF / PDF です。
  iPhone の HEIC 画像は「要確認」に入るので、カメラの設定を「互換性優先」にするか JPEG で保存してください。
- 2MB を超える画像は、ドライブのサムネイル機能で縮小した画像で読み取ります。
- 店名はレシート上部の「住所・電話番号・日付ではない最初の行」を使っています。ロゴ画像だけの店は、店名がずれることがあります。
- 金額は「合計」「お支払金額」などの行の金額を使います(小計・税額・お預り・お釣りは除外)。
  読み取れなかったときはファイル名が `金額不明円` になり、ログのメモ欄に記録されます。
- 誤って振り分けられたものは、ログのファイルURLから開いて手で直してください。

## テスト

読み取り処理(`src/Parser.js`)は Google のサービスに依存しないので、Node.js でテストできます。

```sh
npm test
```
